# Eventify

Проект для управления событиями с использованием Spring Boot и PostgreSQL.

> Данный проект полностью спроектирован и написан мной с нуля на основе технического задания (ТЗ) и OpenAPI/Swagger спецификации. Это самостоятельная Enterprise-разработка а не готовый шаблон.

### 🛠 Архитектурные решения и реализованные модули: 
* **Безопасность и Аутентификация (Spring Security + JWT):** 
  * Полностью с нуля реализовал модуль авторизации на базе JWT-токенов (JwtAuthenticationFilter).
  * Настроил кастомный конфиг безопасности (SecurityConfig) с разграничением прав для обычных пользователей и администраторов.
  * Интегрировал шифрование конфиденциальных данных и паролей (CryptoConfig).
* **Оптимизация и Кэширование (Redis / Redisson):**
  * Вместо стандартного кэша в памяти настроил продвинутую конфигурацию распределенного кэширования через **Redisson** (`RedissonCacheConfig`).
  * Реализовал прецизионный сброс кэша списков (@CacheEvict(value = "bookingsList")) при изменении состояний,чтобы избежать устаревания данных. *
* **Решение проблем конкурентного доступа (Race Condition):**
  * Защитил систему от "овербукинга" при покупке билетов с помощью **пессимистических блокировок** на уровне базы данных (@Lock(LockModeType.PESSIMISTIC_WRITE)).
  * Написал безопасную логику удаления бронирований с консистентным возвратом мест в систему (eventRepository.save).
* **Инфраструктура и Тестирование (Docker, Liquibase, JUnit5):**
  * Создал модуль автоматического заполнения базы данных (AdminInitializer) для создания первичных учетных записей при старте.
  * Настроил версионирование схемы базы данных с помощью миграций **Liquibase**, обеспечив контролируемое создание таблиц, индексов и связей.
  * Подготовил конфигурацию application.yml с разделением профилей окружения.
  * Написал интеграционные и модульные тесты (**JUnit 5**, **Mockito**) для проверки ключевых сервисов и контроллеров приложения.

### Запуск базы данных
В корне проекта находится файл `docker-compose.yml`, который поможет вам 
запустить БД PostgreSQL в докер-контейнере (и вам не придется устанавливать
сервер БД локально)
Для запуска используйте следующую команду:

```bash
docker-compose up -d --force-recreate
```

**Важно:** Если вы уже запускали контейнер ранее без init-скрипта,
обязательно используйте флаг `--force-recreate` для пересоздания контейнера с
новой схемой.

#### Параметры команды:
- `up -d` - запуск контейнеров в фоновом режиме
- `--force-recreate` - пересоздание контейнеров при необходимости 
- (перезаписывает существующие)

#### Альтернативные команды:

**Обычный запуск (без пересоздания):**
```bash
docker-compose up -d
```

**Запуск с пересозданием и пересборкой:**
```bash
docker-compose up -d --force-recreate --build
```

После запуска, БД будет доступна локально со следующими параметрами:

- **Хост:** localhost
- **Порт:** 5432
- **База данных:** eventify_db
- **Пользователь:** postgres
- **Пароль:** postgres


**Остановка контейнеров:**
```bash
docker-compose down
```

**Остановка с удалением данных:**
```bash
docker-compose down -v
```

### Проверка статуса

Для проверки статуса контейнеров:

```bash
docker-compose ps
```

Для просмотра логов:

```bash
docker-compose logs postgres
```

### Подключение к базе данных

Для подключения к базе данных через psql:

```bash
docker exec -it eventify-postgres psql -U postgres -d eventify_db
```
